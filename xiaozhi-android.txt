Step-by-step (manual)

# 1. Boot emulator (headless, x86_64, Android 14)
source ~/.android-env
nohup $ANDROID_HOME/emulator/emulator -avd xiaozhi_test \
    -no-window -no-audio -gpu swiftshader_indirect -no-snapshot \
    > /tmp/emulator.log 2>&1 &

# 2. Wait for boot
adb wait-for-device
until [ "$(adb shell getprop sys.boot_completed | tr -d '\r')" = "1" ]; do sleep 2; done

# 3. Install + launch
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell pm grant com.xiaozhi.client.debug android.permission.RECORD_AUDIO
adb shell am start -n com.xiaozhi.client.debug/com.xiaozhi.client.MainActivity

# 4. Watch logs
adb logcat -s OpusCodec:I ActivationManager:V okhttp.OkHttpClient:I WebSocketProtocol:V AndroidRuntime:E

# 5. Screenshot to view UI
adb exec-out screencap -p > screen.png

# 6. Stop
adb emu kill
What to look for in logcat
Sign
I OpusCodec: Native opus + opus_jni loaded
I okhttp.OkHttpClient: --> POST https://api.tenclass.net/xiaozhi/ota/
I okhttp.OkHttpClient: <-- 200 https://api.tenclass.net/xiaozhi/ota/
I okhttp.OkHttpClient: --> POST .../ota/activate (every 5 s)
E OpusCodec: Failed to load native opus libs
Notes
- Emulator is headless (no GUI window). Use screencap + uiautomator dump to inspect UI.
- If you want a windowed emulator, drop -no-window from the start command (needs a display).
- The emulator can't actually capture audio meaningfully for voice chat — for end-to-end voice testing, install on a real phone via adb -d install -r app/build/outputs/apk/debug/app-debug.apk after enabling USB debugging.
